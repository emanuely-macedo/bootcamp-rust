# 🦀 Bootcamp Rust

Repositório criado para armazenar os exercícios, desafios e projetos desenvolvidos durante as aulas práticas do **Bootcamp Santander - Rust AI**.

## 📚 Objetivos

- Aprender os fundamentos da linguagem **Rust**;
- Desenvolver aplicações utilizando boas práticas de programação;
- Explorar conceitos como:
  - Variáveis e tipos de dados;
  - Controle de fluxo;
  - Funções;
  - Structs e Enums;
  - Ownership, Borrowing e Lifetimes;
  - Collections;
  - Tratamento de erros;
  - Módulos e Packages;
  - Cargo;
  - Desenvolvimento de projetos práticos.

## 🚀 Tecnologias

- Rust
- Cargo
- Visual Studio Code

## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/bootcamp-rust.git
```

Acesse a pasta desejada:

```bash
cd bootcamp-rust
```

Execute o projeto:

```bash
cargo run
```

Ou compile manualmente:

```bash
cargo build
```
